# VaakSetu — Hinglish NLU for Indian E-commerce

**Live Demo:** https://vaaksetu.streamlit.app

Hinglish intent classification + NER on code-switched 
Indian e-commerce queries.

- Intent Accuracy: 100% (5 classes)
- NER F1: 0.75 (6 entity types)
- Dataset: 1,000 annotated Hinglish queries
- Model: MuRIL fine-tuned with weighted CrossEntropyLoss
